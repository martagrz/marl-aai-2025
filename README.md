# Multi-agent Reinforcement Learning and Agentic AI

## Topics covered: 
- RL (MDP, Value iteration, Policy iteration, Q-learning)
- Deep RL (Deep Q-learning, DDQN, Policy Gradient Methods: Actor-Critic, PPO)
- Games as models of multi-agent interaction (Normal form games, Stochastic Games, POSG)
- Solution Concepts (Equilibrium, equilibrium refinement)
- MARL Challenges
- MARL in Games 
- Deep MARL
